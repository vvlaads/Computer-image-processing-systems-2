### Описание

Программа должна принимать на видео, первым кадром которого является крупное
изображение объекта, положение которого необходимо отследить. На каждом кадре видео,
где данный объект виден, вокруг него должна рисоваться рамка с подписью. В примере
объект прямоугольный и плоский, рамка должна максимально соответствовать реальному
положению и границам объекта.
Для простых алгоритмов поиска ключевых точек лучше выбирать объекты с большим
количеством текстур.

## Теоретическая база

Для отслеживания объекта используются ключевые точки изображения. Это характерные участки, например углы, пересечения
линий и другие детали, которые можно обнаружить на разных кадрах видео.

Для поиска ключевых точек применяется алгоритм **SIFT** (Scale-Invariant Feature Transform). Он обнаруживает характерные
точки и вычисляет их дескрипторы — числовые описания локального окружения каждой точки. Дескрипторы используются для
поиска соответствий между кадрами.

Для сопоставления дескрипторов используется `BFMatcher` из OpenCV. Для каждого дескриптора находятся два ближайших
кандидата, после чего применяется проверка Лоу (Lowe's ratio test). Совпадение принимается, если расстояние до лучшего
кандидата меньше 75% расстояния до второго.

Для определения положения объекта используется гомография — преобразование, позволяющее определить новое положение точек
плоского объекта при изменении ракурса. Матрица преобразования вычисляется методом **RANSAC**, который помогает
исключить
ошибочные соответствия между ключевыми точками.

## Описание разработанной системы

Программа реализована на Python с использованием библиотеки OpenCV и библиотеки NumPy для работы с массивами координат.

### Алгоритм работы программы

1. **Инициализация.** Программа открывает видео, считывает первый кадр и принимает его границы за начальное положение
   объекта.
   На первом кадре обнаруживаются ключевые точки **SIFT** и вычисляются их дескрипторы.
2. **Обработка кадров.** Для каждого следующего кадра обнаруживаются ключевые точки и вычисляются дескрипторы.
3. **Сопоставление точек.** Дескрипторы текущего кадра сравниваются с дескрипторами последнего успешно обработанного
   опорного
   кадра. Применяется проверка Лоу для отсеивания неоднозначных совпадений.
4. **Проверка соответствий.** Если совпадений достаточно, с помощью **RANSAC** вычисляется матрица гомографии.
   Проверяется
   количество согласованных точек и их доля среди найденных совпадений.
5. **Определение границ объекта.** Матрица гомографии применяется к углам объекта, благодаря чему определяется его новое
   положение на кадре. Дополнительно проверяется корректность полученного четырёхугольника.
6. **Отрисовка результата.** Если объект успешно обнаружен, вокруг него рисуется зелёная рамка, добавляется подпись и
   отмечаются согласованные ключевые точки. Если обнаружение не удалось, выводится надпись Failed.
7. **Сохранение результата.** Обработанные кадры записываются в выходной видеофайл. Просмотр можно остановить клавишей
   `q`.

После успешного обнаружения текущий кадр становится новым опорным кадром. Это позволяет отслеживать постепенное
перемещение и изменение ракурса объекта.

Для отсеивания ненадёжных результатов используются следующие пороговые значения:

| Параметр           | Значение | Назначение                                                  |
|--------------------|----------|-------------------------------------------------------------|
| RATIO_THRESHOLD    | 0,75     | Фильтрация неоднозначных совпадений                         |
| RANSAC_THRESHOLD   | 5,0      | Допустимое отклонение при проверке соответствий, в пикселях |
| MIN_GOOD_MATCHES   | 10       | Минимальное количество совпадений после проверки Лоу        |
| MIN_RANSAC_INLIERS | 10       | Минимальное количество согласованных соответствий           |
| MIN_INLIER_RATIO   | 0,4      | Минимальная доля согласованных соответствий — 40%           |

Эти значения используются для уменьшения вероятности ошибочного определения положения объекта. Они являются
настраиваемыми параметрами алгоритма.

## Результаты работы и тестирования системы

Для проверки работы алгоритма были использованы три тестовых видео и одна собственная видеозапись. Для каждого видео
сохранялся результат обработки с рамкой вокруг обнаруженного объекта и подписью. Если объект не удавалось обнаружить, на
кадре отображалась надпись Failed.

зафиксировал потери отслеживания.

### Тест 2

| Видео       | Всего кадров | Успешно отслежено | Не обнаружено | Успешность, % |

Результаты показывают, что алгоритм смог обнаруживать объект на большей части обработанных кадров. При этом доля
успешного обнаружения не характеризует точность положения рамки сама по себе: для оценки качества отслеживания также
необходимо визуально проверить обработанные видео и убедиться, что рамка соответствует границам объекта.

## Выводы

В ходе лабораторной работы была реализована программа отслеживания плоского объекта на видео с использованием Python,
OpenCV и NumPy.

Для обнаружения ключевых точек применялся алгоритм **SIFT**, для сопоставления дескрипторов — `BFMatcher` и проверка
Лоу.
Положение объекта на последующих кадрах определялось с помощью матрицы гомографии, вычисляемой методом RANSAC.

Алгоритм был протестирован на трёх тестовых видео и одной собственной видеозаписи. Доля успешного обнаружения составила
от 94,98% до 100% по результатам проведённых тестов.
